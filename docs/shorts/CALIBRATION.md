# 인스타·유튜브 실제 앱에서 자막 위치와 표지 잘림 확인하기

자막 안전 영역과 표지 영역의 기본값은 설계값입니다. 앱 화면은 기기와 버전마다 다르므로 실제 표시 결과로 한 번 맞춥니다.

## 준비

```bash
pnpm shorts calibrate
```

| 파일 | 내용 |
| --- | --- |
| `calibration_reels_shorts_1080x1920.mp4` | 12초 눈금 영상: y 좌표 눈금(60px), 현재 자막 영역(인스타 초록 · 유튜브 빨강), 오른쪽 여백선, 격자 잘림선(4:5 파랑 · 3:4 주황 · 1:1 분홍) |
| `calibration_cover_1080x1920.jpg` | 같은 눈금의 표지 이미지 |
| `platforms.template.json` | 조정값 템플릿 |

## 인스타그램 (테스트 계정 권장)

1. 비공개 테스트 계정을 쓰면 실제 팔로워에게 노출되지 않습니다.
2. 릴스 만들기 → 눈금 영상 선택 → **커버 수정** → 카메라 롤에서 `calibration_cover_1080x1920.jpg` 선택.
   - 커버 편집 화면에서 **프로필 격자 미리보기**를 캡처합니다(①).
3. 게시 후 캡처합니다.
   - ② 릴스 재생 화면(아래쪽 계정명·설명, 오른쪽 버튼이 보이는 상태)
   - ③ 프로필 격자에 보이는 썸네일
   - ④ 홈 피드에 보이는 모습(있다면)
4. 읽을 값
   - ②에서 아래쪽 설명·계정명 영역이 **처음 가리는 눈금 y값** → `instagram_reels.captionBottomY` 는 이 값보다 40px 이상 위로
   - ②에서 오른쪽 버튼이 **시작되는 x값** → `marginRight = 1080 - x + 20`
   - ②에서 위쪽 아이콘이 **끝나는 y값** → `topSafeY`
   - ③에서 보이는 테두리 색(파랑 4:5 · 주황 3:4 · 분홍 1:1)과 위·아래 끝 눈금 → `coverTextArea.top/bottom` 을 그 범위 안쪽으로 각각 120px 이상 들여서
5. 다 확인했으면 테스트 게시물은 지워도 됩니다.

## 유튜브 쇼츠

1. 일부 공개(unlisted) 또는 비공개로 눈금 영상을 업로드합니다.
2. 휴대폰 앱에서 재생 화면을 캡처합니다(아래 제목·채널·구독 버튼, 오른쪽 버튼이 보이는 상태).
3. 위와 같은 방식으로 `youtube_shorts.captionBottomY`, `marginRight`, `topSafeY` 를 읽습니다.

## 값 적용

`platforms.template.json` 을 고쳐 `data/shorts/platforms.json` 으로 저장합니다. 다음 렌더부터 적용되고 코드는 고치지 않아도 됩니다.

```json
{
  "instagram_reels": { "captionBottomY": 1250, "marginRight": 180, "coverTextArea": { "top": 480, "bottom": 1440 } },
  "youtube_shorts": { "captionBottomY": 1360 },
  "common": { "captionBottomY": 1250, "coverTextArea": { "top": 480, "bottom": 1440 } }
}
```

`common`(공용)은 두 플랫폼 중 더 위쪽 자막 위치와 더 넓은 여백을 쓰세요.

캡처 사진을 보내 주시면 값을 대신 읽어 반영하겠습니다.

## 현재 기본값과 확인이 필요한 점

| 항목 | 기본값 | 확인할 것 |
| --- | --- | --- |
| 인스타 자막 하단 | y 1290 | 설명·계정명 영역과 겹치는지 |
| 유튜브 자막 하단 | y 1380 | 제목·구독 영역과 겹치는지 |
| 오른쪽 여백 | 170px | 좋아요·댓글 버튼과 겹치는지 |
| 릴스 표지 제목 영역 | y 445~1475 (4:5 격자 안쪽 160px) | **인스타 프로필 격자가 4:5 인지 3:4 인지.** 2025년 초 3:4로 바뀌었다는 기억이 있으나 확인하지 못함. 3:4라면 보이는 범위가 240~1680 이라 현재 값도 안에 들어가지만, 여백을 다시 맞출 수 있음 |
